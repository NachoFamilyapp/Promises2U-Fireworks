# Promises2U-Fireworks
Multi-screen synchronized fireworks controller
Promises2U Fireworks – wijzigingen

- Vier bestaande landschappen als aanklikbare miniaturen in een galerij.
- De bestaande knop ACHTERGROND TOEPASSEN stuurt de selectie naar Firebase.
- De emoji is vervangen door een volledige SVG-Kerstman met bewegende armen en benen.
- De Kerstman gebruikt dezelfde Firebase-starttijd op scherm 1 en 2 voor de overgang.
- Bestaande vuurwerk-, sneeuw-, projectie-, login- en schermbediening zijn behouden.

Installatie: vervang index.html in GitHub, laat backgrounds/ met de acht JPG-bestanden staan, commit op main en wacht op Vercel. Test daarna scherm 1 en 2.

Niet live gedeployed of op de fysieke schermopstelling getest.
